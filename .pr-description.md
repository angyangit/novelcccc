## Core Decisions (ADR-007)

### 1. GenrePack Identity Triple
- `pack_id`: Stable logical identifier
- `version`: Semantic version
- `content_hash`: SHA-256 canonical hash (ADR-005)

**Guarantees**:
- Same (pack_id, version) → same content_hash
- Tampering detected by hash verification
- Idempotent loading with conflict detection

### 2. Extension Namespace Isolation
- **Core Canon**: Entity identity, relationships, events, commits (unchanged)
- **Genre Extension**: World mechanics, typed state, transition rules
- Namespaced fields: `fantasy.eastern.cultivation.realm_level`
- Undeclared namespaces → explicit rejection

### 3. Project Binding Contract
- Projects bind frozen (pack_id, version, content_hash)
- No silent replacement based on keywords or similarity
- Multi-project isolation: different Packs per project
- Version upgrades require explicit migration

### 4. Two Frozen Anchors (P3)
- `urban.business.realistic`: Modern business, no supernatural
- `fantasy.eastern.progression`: Cultivation, realms, progression

### 5. Explicit Failure Semantics
- Pack not found → `GenrePackNotFoundError`
- Hash mismatch → `GenrePackHashMismatchError`
- Unknown extension → `UnknownExtensionNamespaceError`
- No silent fallback to "default" Packs
