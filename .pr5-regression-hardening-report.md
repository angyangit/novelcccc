## Defect A: Missing Declarations Not Blocked

### Problem (Before Fix)

The checker only validated the GitHub URL when a "Canonical Repository" header was detected:

```python
# BEFORE - Could silently pass if section deleted
if file_path.name in ["AGENTS.md", "README.md", "PROJECT_STATUS.md"]:
    if "Canonical Repository" in content or "CANONICAL REPOSITORY" in content:
        if CORRECT_CANONICAL not in content:
            errors.append(f"MISSING_GITHUB: ...")
```

**Vulnerabilities**:
1. If entire canonical section was deleted: **No error**
2. If correct GitHub URL appeared only in historical section: **False positive PASS**
3. Test had `assert True` instead of checking actual errors

### Solution (After Fix)

```python
# AFTER - Explicitly requires canonical section
if file_path.name in ["AGENTS.md", "README.md", "PROJECT_STATUS.md"]:
    has_canonical_header = (
        "Canonical Repository" in content or "CANONICAL REPOSITORY" in content
    )
    
    if not has_canonical_header:
        errors.append(
            f"MISSING_CANONICAL_SECTION: {file_path} must have a Canonical Repository section"
        )
        return errors
    
    # Section exists - verify correct URL within that section
    lines = content.split("\n")
    in_canonical_section = False
    found_correct_url_in_canonical = False
    
    for line in lines:
        if "canonical repository" in line.lower():
            in_canonical_section = True
        elif line.startswith("##") and in_canonical_section:
            in_canonical_section = False
        
        if in_canonical_section and CORRECT_CANONICAL in line:
            found_correct_url_in_canonical = True
            break
    
    if not found_correct_url_in_canonical:
        errors.append(
            f"MISSING_GITHUB: {file_path} has Canonical Repository section "
            f"but does not declare {CORRECT_CANONICAL} within that section"
        )
```

**Improvements**:
1. ✅ Missing canonical section: **MISSING_CANONICAL_SECTION error**
2. ✅ Wrong URL in canonical section: **MISSING_GITHUB error**
3. ✅ Correct URL only in historical section: **MISSING_GITHUB error**
4. ✅ Section-aware validation prevents false positives

## Defect B: Tests Used Shared Fixed Paths

### Problem (Before Fix)

Tests created files at shared system paths:

```python
# BEFORE - Potential conflicts and pollution
with tempfile.NamedTemporaryFile(mode="w", suffix=".md", delete=False) as f:
    f.write(content)
    f.flush()
    path = Path(f.name)

try:
    errors = check_file(path)
    # ...
finally:
    path.unlink()

# Special case even worse:
agents_path = path.parent / "AGENTS.md"  # Writes to /tmp/AGENTS.md
```

**Vulnerabilities**:
1. Multiple test runs could conflict on `/tmp/AGENTS.md`
2. Tests could overwrite external files
3. Failed tests could leave files behind
4. Not using pytest's built-in isolation

### Solution (After Fix)

```python
# AFTER - Proper pytest isolation
def test_correct_github_canonical_passes(tmp_path):
    """Test that correct GitHub canonical declaration passes."""
    test_file = tmp_path / "AGENTS.md"
    test_file.write_text(
        """# Test File

## CANONICAL REPOSITORY

**Canonical Repository**: `https://github.com/angyangit/novelcccc.git`
**Branch**: `main`

AI agents must use GitHub for current work.
"""
    )
    
    errors = check_file(test_file)
    assert len(errors) == 0, f"Should pass but got errors: {errors}"
```

**Improvements**:
1. ✅ Each test gets unique temporary directory (`tmp_path` fixture)
2. ✅ Automatic cleanup by pytest
3. ✅ No shared file paths
4. ✅ No risk of external file pollution
5. ✅ Proper test isolation
