## Root Cause

Three active entry points incorrectly declared GitLab as "sole canonical platform":

1. **AGENTS.md** - Line 5: "This project uses GitLab as the sole canonical platform"
2. **README.md** - Line 7: Canonical Repository pointed to GitLab
3. **PROJECT_STATUS.md** - Line 22: Canonical Repository pointed to GitLab

**Incorrect URL**: `https://gitlab.com/angyang582821422/novelcccc.git`

**Impact**: AI agents would incorrectly attempt to fetch from `gitlab/main` instead of canonical `origin/main`, causing confusion about current authoritative state.
